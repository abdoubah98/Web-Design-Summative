About GameZone

GameZone is a specialist gaming store created for the CPU4104 Web Development assignment.

Our purpose

We help customers find consoles, games and gaming accessories in a simple online shop experience. The website is front-end only and demonstrates HTML structure, CSS styling, responsive design and JavaScript DOM manipulation.

What the website demonstrates

  • Semantic HTML pages with clear navigation.
  • Mobile-first styling using custom CSS.
  • Interactive shopping cart features using JavaScript.
  • Accessibility improvements including labels, alt text and strong contrast.
